# Detailed rat model verification — 2026-09-04

Contribution category: **presentation**. Gameplay outcomes do not change;
Brogue CE remains authoritative. Research/export instructions are in
[gzdoom-model-authoring.md](gzdoom-model-authoring.md). The editable model and
provenance are in [assets/monsters/rat](../assets/monsters/rat/README.md).

## Delivered assets

The existing `MK_RAT` / `BrogueMonsterK01` now uses the original detailed gray
scavenger model, including on floor one. It has 14,868 triangles, 8,429 exported
vertices including UV seams, and one 1024×1024 RGB skin. The 76 editable anatomy
objects remain separate in Blender. The preview stage is excluded from the OBJ.

The roster generator preserves the custom rat geometry and assigns its dedicated
skin on regeneration. The registry change is confined to the rat's skin/source/
generator metadata; the only MODELDEF binding change is its skin path. Native
frontend source and `brogue_monsters.zs` are byte-identical to the recorded
baseline. All authored geometry and texture painting are original Project Broom
assets under CC-BY-SA-4.0; no third-party art was imported.

## Source handoff and limitations

`rat.blend` reopens with `Project Broom - Rat` active, 81 scene objects (76 model
parts plus floor, camera, and three lights), one packed 1024×1024 texture, and
no linked libraries. The normal user Blender process can read the file. The
authoring helper was exercised end to end through the live MCP; background
verification uses the installed executable path because the MCP server's
optional CLI tools lack `BLENDER_PATH`.

This is a static pose with the existing bridge's whole-actor animation. It does
not include skeletal walking, jaw, ear, or tail cycles, a PBR/normal-map skin,
or a new sprite fallback. No performance benchmark or independent gameplay
parity claim is made. Save bytes for `.blend` are application metadata dependent;
deterministic guarantees apply to the runtime OBJ/PNG and resource packaging.
