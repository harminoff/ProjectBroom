# Bloat — BRG-M06

Original Project Broom membrane mesh, purple veined diffuse skin and six skeletal
clips, CC-BY-SA-4.0. Created through Blender MCP using the shared skeletal method.

Reproducible master: `python -m tools.monster_models.bloat_animation`.
`bloat-animated.blend` contains the editable weighted membrane, seven-bone rig,
packed skin and six Actions. Rebuild with `blender_skeletal.py -- MK_BLOAT` in
Blender. Reconcile manual changes with the generator before rebuilding.

See [implementation and verification](../../../docs/bloat-animation.md).
