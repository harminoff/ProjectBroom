# Pit bloat — BRG-M07

Original Project Broom blue membrane skin and weighted model, CC-BY-SA-4.0.
This is Brogue's rare bloat subspecies, sharing the bloat's connected membrane,
seven-bone rig and six animations. Blue diffuse color distinguishes it from
the purple bloat without adding eyes, organs, glow or gameplay effects.

Created through Blender MCP. `pit-bloat-animated.blend` is the editable source
with packed skin and Actions. Reproducible master:
`python -m tools.monster_models.pit_bloat_animation`. Rebuild the Blender source
with `blender_skeletal.py -- MK_PIT_BLOAT`; reconcile manual edits first.

See [verification and limits](../../../docs/pit-bloat-animation.md).
