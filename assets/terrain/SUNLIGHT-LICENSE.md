# First-floor sunlight presentation

The broken-ceiling material, volumetric-ray mesh, and ray texture are original
Project Broom assets generated by `tools/sunlight_assets.py`. The ceiling
material incorporates the existing original Project Broom `BRGROCK.png` cave
texture as its surrounding stone.

They are dedicated to the public domain under CC0 1.0. No third-party texture,
model, sound, or reference-game asset is included. The ceiling rim reuses
Project Broom's existing `BRGROCK.png` material at runtime.

These assets are presentation-only. Placement reads Brogue CE's copied
`SUNLIGHT_POOL` terrain, applies only on depth 1, and has no collision, damage,
AI, turn, or gameplay-randomness behavior.
