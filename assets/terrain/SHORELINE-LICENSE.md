# Shoreline material resources

The procedural shader `mod/BrogueDoom/shaders/shoreline.fp`, binary neighbor
data textures under `mod/BrogueDoom/shaders/shoreline/`, and material alias
definitions generated by `tools/shoreline_assets.py` are original Project
Broom work, dedicated under CC0-1.0.

The generator creates eight binary texels per normalized neighbor mask. It
does not sample or modify external images. The material aliases reference
existing Project Broom earth, moss, flagstone, bridge and water artwork;
their existing provenance and licensing remain unchanged. No textures, meshes
or source code from the research examples were imported.

The shader's warp is an original sine-based implementation retaining the
existing water's scale and pace, integrated with spatial edge attenuation.
