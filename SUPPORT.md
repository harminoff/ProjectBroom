# Support

- Use the bug issue form for reproducible defects.
- Use the parity issue form when Project Broom differs from the pinned Brogue
  CE behavior.
- Use the presentation issue form for visual, audio, UI, or accessibility work.
- Use GitHub Discussions for setup questions and contribution design.

Include the Project Broom version, Windows version, seed, depth, action
sequence, and diagnostic bundle. Generated campaign JSON and crash archives
may contain large or machine-specific data; attach them only when requested.
