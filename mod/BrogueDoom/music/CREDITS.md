# Project Broom background music

Project Broom uses the same six cave and dungeon ambience compositions chosen
for Brogue CE Android. These files are the smaller source-distributed Ogg/MP3
versions rather than that port's 22,050 Hz WAV conversions. Each linked source
page identified the work as CC0 when rechecked on 2026-09-13.
